✨ First vs Second Conditional

🔹 FIRST CONDITIONAL (real / possible)

If + present simple, will / might / could + base verb

If I see a friend, I will say hello.

We use will when we are sure. Might / could show less certainty.

⚡ Zero Conditional: When the result is always true, we use present simple in both parts.
If you heat water, it boils.

🔸 SECOND CONDITIONAL (unreal / imaginary)

If + past simple, would + base verb

If I had a superpower, I would fly.

We use it for unreal or unlikely situations (dreams, "if I were you" etc.).

✅ Short forms accepted: don't, won't, I'd, wouldn't.
